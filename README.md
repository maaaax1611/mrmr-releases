# mrmr

Hold a key, speak, let go, and what you said is typed where your cursor is. mrmr runs entirely on your PC: your voice never leaves it.

## Download

**[Download mrmr for Windows](https://github.com/maaaax1611/mrmr-releases/releases/latest/download/mrmr-setup.exe)**

Needs Windows 10 or 11 (64-bit).

## Install

1. Open `mrmr-setup.exe`.
2. Windows may say "Windows protected your PC", because mrmr isn't signed by a paid certificate. Click **More info**, then **Run anyway**.
3. On the first start, mrmr downloads its speech model once (190–574 MB), so it needs internet then. After that it works offline.

If Windows asks, allow desktop apps to use the microphone: Settings → Privacy → Microphone.

## Use

Hold **AltGr** (right of the space bar), speak, and let go. You can change the key in mrmr's settings.

## Updates

mrmr checks for new versions when it starts and shows **Update** in its window. One click installs it.
